防火牆規則比對

比對新舊規則、找出被遮蔽的規則，並把 log 對應到命中的規則。所有處理都在瀏覽器內完成，不會上傳；內容會自動暫存在這台裝置。

  1. 1貼上舊版與新版
  2. 2即時顯示差異
  3. 3匯出 CSV
規則格式

動作協定來源->目的埠號

範例：允許 TCP 10.0.0.0/24 -> 任意 443　或　allow tcp 10.0.0.0/24 -> any 80,443

更多寫法說明（別名、埠號、註解）
  • 動作：允許（也可寫 allow、permit、accept、pass）或 拒絕（deny、drop、block、reject）。協定：TCP、UDP、ICMP 或「任意」（any、all、*）。
  • 來源與目的：IPv4 位址（如 10.0.0.5）、網段（如 10.0.0.0/24）、IPv6 位址或網段（如 2001:db8::/32）或「任意」。滑鼠移到結果中的網段上，會顯示它的位址範圍。
  • 埠號：單一埠（443）、範圍（8080-8090）、多個埠（80,443,8080-8090，逗號後不加空白）、服務名稱（http、https、ssh、dns、ftp、telnet、smtp、ntp、smb、rdp、mysql）或「任意」。ICMP 的埠號請寫「任意」。
  • 服務物件群組：先用一行定義變數，再在埠號欄使用，例如 $WEB = 80,443,8080-8090，之後寫 allow tcp any -> 10.0.0.5 $WEB。變數要先定義後使用，定義行不算規則。
  • 一行一條，英文不分大小寫。# 開頭的行是註解（灰色），空白行會略過。輸入框左側有行號，格式錯誤的行標紅、錯的欄位會有紅色波浪底線，被前面規則遮蔽或冗餘的行標黃。
  1. 1貼上規則
  2. 2貼上或匯入 Log
  3. 3即時顯示對應結果
Log 格式

日期時間協定來源->目的埠號動作（可省略）

範例：2026-10-08 09:15:02 TCP 203.0.113.7 -> 192.168.1.10 443 允許

更多寫法說明（匯入檔案、對應方式）
  • 來源與目的必須是單一 IP 位址（IPv4 或 IPv6），埠號是單一數字或服務名稱。ICMP 的埠號寫「任意」。動作可寫「允許／拒絕」或 allow／deny。
  • 一行一筆。# 開頭的行是註解，空白行會略過。
  • 也可以按「匯入 Log 檔」，或把檔案拖進 Log 輸入框。支援 .txt、.log、.csv（8 MB 以內）。檔案很大時會在背景計算，並以虛擬捲動顯示結果。CSV 的欄位順序同上，可以沒有「->」欄，第一列若是標題會自動略過。
  • 對應方式：由上往下，第一條符合協定、來源、目的、埠號的規則，就是這筆 log 命中的規則。沒有命中的 log 會套用你選的預設政策。

示範資料中的位址都是虛構的（內部網段與文件保留網段）。本工具只依你貼上的規則做比對，不能取代正式的變更審查或資安事件分析。遮蔽與冗餘分析只檢查「某一條前面的規則是否完整涵蓋它」，不處理多條規則合併後才涵蓋的情況。含逗號的多埠號規則會當成一條規則比對，不會拆成多條。僅供課堂與自學練習。
