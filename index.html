防火牆規則比對

比對新舊規則的差異，也能把連線紀錄（log）對應到命中的規則。所有處理都在你的瀏覽器內完成，不會上傳資料。

  1. 1貼上舊版與新版
  2. 2按下「比對」
  3. 3查看差異

規則寫法

動作協定來源->目的埠號

  • 動作：允許 或 拒絕。協定：TCP、UDP、ICMP 或「任意」。
  • 來源與目的：IPv4 位址（如 10.0.0.5）、網段（如 10.0.0.0/24）或「任意」。
  • 埠號：單一埠（443）、範圍（8080-8090）或「任意」。ICMP 的埠號請寫「任意」。
  • 一行一條。# 開頭的行是註解，空白行會略過。

範例：允許 TCP 10.0.0.0/24 -> 任意 443

  1. 1貼上規則
  2. 2貼上 Log
  3. 3按下「對應」

Log 寫法

日期時間協定來源->目的埠號動作（可省略）

  • 來源與目的必須是單一 IPv4 位址，埠號是單一數字。ICMP 的埠號寫「任意」。
  • 一行一筆。# 開頭的行是註解，空白行會略過。
  • 也可以按「匯入 Log 檔」，或把檔案拖進 Log 輸入框。支援 .txt、.log、.csv（2 MB 以內）。CSV 的欄位順序同上，可以沒有「->」欄，第一列若是標題會自動略過。
  • 對應方式：由上往下，第一條符合協定、來源、目的、埠號的規則，就是這筆 log 命中的規則。

範例：2026-10-08 09:15:02 TCP 203.0.113.7 -> 192.168.1.10 443 允許

示範資料中的位址都是虛構的（內部網段與文件保留網段）。本工具只依你貼上的規則做比對，沒有模擬預設政策，也不能取代正式的變更審查或資安事件分析。僅供課堂與自學練習。
