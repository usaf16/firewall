# 防火牆規則比對

純靜態網頁（只用 HTML、CSS、JavaScript），用來：

1. **規則比對**：貼上舊版與新版防火牆規則，找出新增、刪除、修改與不變的規則。
2. **規則與 Log 對應**：貼上規則與連線紀錄（log），看每一筆 log 命中哪一條規則。

所有處理都在瀏覽器內完成，不會上傳任何資料。僅供課堂與自學練習。

線上版：https://usaf16.github.io/firewall/

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需要安裝或啟動伺服器。

## 規則寫法

```
動作 協定 來源 -> 目的 埠號
```

| 欄位 | 可填的值 |
|---|---|
| 動作 | `允許`、`拒絕` |
| 協定 | `TCP`、`UDP`、`ICMP`、`任意` |
| 來源、目的 | IPv4 位址（`10.0.0.5`）、網段（`10.0.0.0/24`）、`任意` |
| 埠號 | 單一埠（`443`）、範圍（`8080-8090`）、`任意`（ICMP 請填 `任意`） |

範例：`允許 TCP 10.0.0.0/24 -> 任意 443`

一行一條。`#` 開頭的行是註解，空白行會略過。

## Log 寫法

```
日期 時間 協定 來源 -> 目的 埠號 [動作]
```

範例：`2026-10-08 09:15:02 TCP 203.0.113.7 -> 192.168.1.10 443 允許`

- 來源與目的必須是單一 IPv4 位址，埠號是單一數字（ICMP 填 `任意`）。
- 動作可以省略。
- 可以用「匯入 Log 檔」或拖曳檔案匯入 `.txt`、`.log`、`.csv`（2 MB 以內）。CSV 欄位順序為日期、時間、協定、來源、目的、埠號、動作，不需要 `->` 欄，第一列若是標題會自動略過。

## 比對邏輯

- **規則比對**：以「協定、來源、目的、埠號」作為比對條件。兩邊條件相同且動作相同為「不變」；條件相同但動作不同為「修改」；只出現在一邊的為「新增」或「刪除」。重複的規則只算一次。
- **規則與 Log 對應**：規則由上往下比對，第一條符合協定、來源、目的、埠號的規則，就是該筆 log 命中的規則。

## 限制

- 不分析規則順序造成的覆蓋或衝突（規則比對頁）。
- 沒有模擬預設政策，沒有任何規則符合的連線只會標示為「未命中」。
- 不支援特定廠牌或 iptables 的原始格式，需要先轉成上面的寫法。
- 示範資料中的位址都是虛構的。本工具不能取代正式的變更審查或資安事件分析。
