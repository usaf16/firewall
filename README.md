# 防火牆規則比對

純靜態網頁（只用 HTML、CSS、JavaScript），用來：

1. **規則比對**：貼上舊版與新版防火牆規則，找出新增、刪除、修改、順序調整與不變的規則，可切換「左右並排」與「統整」檢視，並匯出 CSV 報告。
2. **規則與 Log 對應**：貼上規則與連線紀錄（log），看每一筆 log 命中哪一條規則，附摘要儀表板、篩選與 CSV 匯出。
3. **規則分析**：標出被前面規則完全覆蓋的「遮蔽」規則與「冗餘」規則。

所有處理都在瀏覽器內完成，不會上傳任何資料。僅供課堂與自學練習。

## 介面特色

- **左右分割**：寬螢幕（1100 px 以上）左邊是輸入，右邊是即時結果；修改輸入後右側自動更新。窄螢幕改為上下排列。
- **語法上色**：輸入框內允許（綠）、拒絕（紅）、協定（藍）、IP、埠號各有顏色，「任意」是灰色，`#` 註解整行淺灰。全站使用等寬字體（Fira Code，沒有時用 Consolas 等）。
- **深色模式**：右上角按鈕切換，選擇會記在瀏覽器裡。預設是淺色。
- **自動暫存**：輸入的規則與 log 會存在瀏覽器的 localStorage，重新整理不會消失。「清除暫存並還原範例」按鈕（要按兩次確認）可以重設。
- **跨區連動**：在「規則與 Log 對應」把滑鼠移到某筆 log（或前 3 名規則）上，左側規則清單會亮起它命中的那一條。
- **網段提示**：滑鼠移到結果中的網段（如 `10.0.0.0/24`）上，會顯示位址範圍與可用主機數。
- **波浪底線**：輸入框內格式錯誤的欄位（打錯的 IP、不存在的變數、不合法的 CIDR 等）會直接畫紅色波浪底線，不用只看下方的錯誤清單。
- **跳轉鎖定**：在 Log 明細的「命中」欄按「跳轉」，會把左側規則清單的游標放到那一行並選取、鎖定亮起；再按一次取消鎖定。
- **大量資料**：Log 明細使用虛擬捲動，只繪製畫面上看得到的列（約 20 列），不限筆數。輸入框的行號與語法上色也只繪製可視範圍，行數再多不會降級。log 文字超過約 150 KB 時，解析與比對改在 Web Worker（背景執行緒）執行並顯示處理中提示；若瀏覽器不允許 Worker（例如直接用 `file://` 開啟），會自動退回主執行緒計算。上限 8 MB。

線上版：https://usaf16.github.io/firewall/

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需要安裝或啟動伺服器。每個輸入框都有「填入範例」按鈕，3 秒內就能體驗。

## 規則寫法

```
動作 協定 來源 -> 目的 埠號
```

| 欄位 | 可填的值 |
|---|---|
| 動作 | `允許`（`allow`、`permit`、`accept`、`pass`）、`拒絕`（`deny`、`drop`、`block`、`reject`） |
| 協定 | `TCP`、`UDP`、`ICMP`、`任意`（`any`、`all`、`*`） |
| 來源、目的 | IPv4 位址（`10.0.0.5`）、網段（`10.0.0.0/24`）、IPv6 位址或網段（`2001:db8::/32`，支援 `::` 縮寫）、`任意` |
| 埠號 | 單一埠（`443`）、範圍（`8080-8090`）、多個埠（`80,443,8080-8090`，逗號後不加空白）、服務名稱（`http`、`https`、`ssh`、`dns`、`ftp`、`telnet`、`smtp`、`ntp`、`smb`、`rdp`、`mysql`）、`任意`（ICMP 請填 `任意`） |

範例：`允許 TCP 10.0.0.0/24 -> 任意 443`，或 `allow tcp 10.0.0.0/24 -> any https`

一行一條，英文不分大小寫。`#` 開頭的行是註解，空白行會略過。

### 服務物件群組（變數）

先用一行定義變數，再在埠號欄使用：

```
$WEB = 80,443,8080-8090
allow tcp 10.0.2.0/24 -> 192.168.1.30 $WEB
```

變數要先定義後使用；變數的值可以是單一埠、範圍、多個埠或服務名稱，也可以引用先前定義的變數（如 `$WEB,3306`），但不能是「任意」。定義行不算規則，不佔規則編號。目前只支援埠號群組，不支援位址群組。

## 輸入框的即時檢查

- 左側有行號。格式錯誤的行會標紅，並在輸入框下方列出原因，例如「第 4 行錯誤：不合法的 CIDR 遮罩格式 (10.0.0.0/33)」、「箭頭請寫成 ->，目前是 -->」。
- 被前面規則遮蔽或冗餘的行會標黃。

## Log 寫法

```
日期 時間 協定 來源 -> 目的 埠號 [動作]
```

範例：`2026-10-08 09:15:02 TCP 203.0.113.7 -> 192.168.1.10 443 允許`

- 來源與目的必須是單一 IP 位址（IPv4 或 IPv6），埠號是單一數字或服務名稱（ICMP 填 `任意`）。
- 動作可以省略。
- 可以用「匯入 Log 檔」或拖曳檔案匯入 `.txt`、`.log`、`.csv`（8 MB 以內）。CSV 欄位順序為日期、時間、協定、來源、目的、埠號、動作，不需要 `->` 欄，第一列若是標題會自動略過。

## 比對邏輯

- **規則比對**：以「協定、來源、目的、埠號」作為比對條件。條件與動作都相同為「不變」；條件相同但動作不同為「修改」；只出現在一邊的為「新增」或「刪除」。條件與動作都沒變、但相對順序改變的規則標為「順序調整」，這在防火牆中屬於高風險異動。重複的規則只算第一次。
- **規則與 Log 對應**：規則由上往下比對，第一條符合協定、來源、目的、埠號的規則，就是該筆 log 命中的規則。沒有命中的 log 套用你選的預設政策（預設拒絕或預設允許）。
- **遮蔽與冗餘**：若某條規則被它前面的某一條規則完整涵蓋，動作不同為「遮蔽」（永遠不會被觸發），動作相同為「冗餘」。

## Log 結果摘要

總解析筆數、允許與拒絕的比例、未命中筆數、與 log 記錄動作不一致的筆數、命中次數最多的前 3 條規則。可篩選「全部」「僅顯示拒絕」「僅顯示未命中／異常」，並匯出 CSV（含最終動作與判定來源）。

## 限制

- 遮蔽與冗餘分析只檢查「單一前面規則是否完整涵蓋」，不處理多條規則合併後才涵蓋的情況。
- 含逗號的多埠號規則會當成一條規則比對（比對與涵蓋判斷會逐段展開），不會拆成多條；因此 `80,443` 與分開寫的 `80`、`443` 兩條，在「規則比對」會被視為不同規則。重疊或相鄰的埠號範圍會自動合併，順序不影響結果。
- 不支援特定廠牌或 iptables 的原始格式，需要先轉成上面的寫法。
- IPv6 不支援內嵌 IPv4 寫法（如 `::ffff:1.2.3.4`）與區域識別碼（`%eth0`）。IPv4 規則不會命中 IPv6 的 log，反之亦然；「任意」兩者都包含。
- 行數超過 5000 行的輸入框會略過逐行即時檢查（上色與波浪底線仍會顯示），按「比對」或「對應」才會完整解析。log 文字很大時，修改後不會即時更新，請按「對應」。
- 差異明細畫面最多顯示前 500 筆，統計與 CSV 匯出包含全部。
- 示範資料中的位址都是虛構的。本工具不能取代正式的變更審查或資安事件分析。

## 檔案結構

```
index.html    首頁
style.css     樣式
core.js       核心邏輯：解析、比對、遮蔽與冗餘分析（不碰畫面，主執行緒與 Worker 共用）
worker.js     背景執行緒：大量 log 的解析與比對
script.js     畫面：輸入框、結果、虛擬捲動、匯出
images/       圖片（logo.svg）
```
