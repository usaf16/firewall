# 防火牆規則比對

純靜態網頁（只用 HTML、CSS、JavaScript），用來：

1. **規則比對**：貼上舊版與新版防火牆規則，找出新增、刪除、修改、順序調整與不變的規則，可切換「左右並排」與「統整」檢視，並匯出 CSV 報告。
2. **規則與 Log 對應**：貼上規則與連線紀錄（log），看每一筆 log 命中哪一條規則，附摘要儀表板、篩選與 CSV 匯出。
3. **規則分析**：標出被前面規則完全覆蓋的「遮蔽」規則與「冗餘」規則。

所有處理都在瀏覽器內完成，不會上傳任何資料。僅供課堂與自學練習。

線上版：https://usaf16.github.io/firewall/

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需要安裝或啟動伺服器。每個輸入框都有「填入範例」按鈕，3 秒內就能體驗。

## 規則寫法

```
動作 協定 來源 -> 目的 埠號
```

| 欄位 | 可填的值 |
|---|---|
| 動作 | `允許`（`allow`、`permit`、`accept`、`pass`）、`拒絕`（`deny`、`drop`、`block`、`reject`） |
| 協定 | `TCP`、`UDP`、`ICMP`、`任意`（`any`、`all`、`*`） |
| 來源、目的 | IPv4 位址（`10.0.0.5`）、網段（`10.0.0.0/24`）、`任意` |
| 埠號 | 單一埠（`443`）、範圍（`8080-8090`）、服務名稱（`http`、`https`、`ssh`、`dns`、`ftp`、`telnet`、`smtp`、`ntp`、`smb`、`rdp`、`mysql`）、`任意`（ICMP 請填 `任意`） |

範例：`允許 TCP 10.0.0.0/24 -> 任意 443`，或 `allow tcp 10.0.0.0/24 -> any https`

一行一條，英文不分大小寫。`#` 開頭的行是註解，空白行會略過。

## 輸入框的即時檢查

- 左側有行號。格式錯誤的行會標紅，並在輸入框下方列出原因，例如「第 4 行錯誤：不合法的 CIDR 遮罩格式 (10.0.0.0/33)」、「箭頭請寫成 ->，目前是 -->」。
- 被前面規則遮蔽或冗餘的行會標黃。

## Log 寫法

```
日期 時間 協定 來源 -> 目的 埠號 [動作]
```

範例：`2026-10-08 09:15:02 TCP 203.0.113.7 -> 192.168.1.10 443 允許`

- 來源與目的必須是單一 IPv4 位址，埠號是單一數字或服務名稱（ICMP 填 `任意`）。
- 動作可以省略。
- 可以用「匯入 Log 檔」或拖曳檔案匯入 `.txt`、`.log`、`.csv`（2 MB 以內）。CSV 欄位順序為日期、時間、協定、來源、目的、埠號、動作，不需要 `->` 欄，第一列若是標題會自動略過。

## 比對邏輯

- **規則比對**：以「協定、來源、目的、埠號」作為比對條件。條件與動作都相同為「不變」；條件相同但動作不同為「修改」；只出現在一邊的為「新增」或「刪除」。條件與動作都沒變、但相對順序改變的規則標為「順序調整」，這在防火牆中屬於高風險異動。重複的規則只算第一次。
- **規則與 Log 對應**：規則由上往下比對，第一條符合協定、來源、目的、埠號的規則，就是該筆 log 命中的規則。沒有命中的 log 套用你選的預設政策（預設拒絕或預設允許）。
- **遮蔽與冗餘**：若某條規則被它前面的某一條規則完整涵蓋，動作不同為「遮蔽」（永遠不會被觸發），動作相同為「冗餘」。

## Log 結果摘要

總解析筆數、允許與拒絕的比例、未命中筆數、與 log 記錄動作不一致的筆數、命中次數最多的前 3 條規則。可篩選「全部」「僅顯示拒絕」「僅顯示未命中／異常」，並匯出 CSV（含最終動作與判定來源）。

## 限制

- 遮蔽與冗餘分析只檢查「單一前面規則是否完整涵蓋」，不處理多條規則合併後才涵蓋的情況。
- 不支援特定廠牌或 iptables 的原始格式，需要先轉成上面的寫法。
- 明細表最多顯示前 1000 筆，摘要與 CSV 匯出包含全部。
- 示範資料中的位址都是虛構的。本工具不能取代正式的變更審查或資安事件分析。
